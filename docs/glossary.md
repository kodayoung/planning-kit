# 용어 정리 (초안)

이 도구에서 쓰는 말을 한 곳에 모아 둔 문서입니다.
같은 것을 다른 이름으로 부르지 않도록, **쓰는 이름 하나**를 정하고 다른 이름은 "같은 말"로 적어 둡니다.

> 초안입니다. 실제로 팀에서 부르는 말과 다르면 고쳐 주세요.

## 핵심 용어

| 쓰는 이름 | 한 줄 뜻 | 같은 말 / 헷갈리는 말 | 어디에 있나 |
|---|---|---|---|
| **기획 도구** | 프론트 화면 위에 기획안을 얹어 보는 이 프로젝트 전체 | planning-kit | 레포 전체 |
| **화면** | 사용자가 보는 한 페이지. 주소(route) 하나에 대응 | 페이지 (KB 의 `pageName`) | `specs/<화면>.yaml` |
| **요소** | 화면 안의 버튼·입력창·표 같은 하나 | 항목 (KB 쪽 부름) | 스펙 파일의 `elements` |
| **스펙** | 화면 하나의 설명 파일. 요소 목록과 찾는 법이 들어 있음 | 스펙 파일, 화면 스펙 | `specs/*.yaml` |
| **스티커** | 화면 위에 띄우는 번호 표시. 누르면 설명 카드가 뜸 | 오버레이 (기술 용어) | `overlay/` |
| **locator** | 요소를 화면에서 찾는 방법 ("역할 + 보이는 글자") | 위치 규칙 | 스펙의 `locator` |
| **KB** | 피그마 기획안에서 뽑아 둔 설명 모음. 설명의 원본 | 기획안 KB, 지식 베이스 | `KB_DIR` 폴더 (레포 밖) |
| **항목** | KB 안의 설명 한 건 (번호, 이름, 설명, 제약) | 요소와 짝을 이룸 | KB 의 `items` |
| **목업** | 아직 없는 API 대신 돌려주는 가짜 응답 | 가짜 응답, mock | `mocks/` |
| **목업 규칙** | 어떤 요청에 어떤 목업을 줄지 적은 표 | routes | `mocks/routes.yaml` |
| **경우** | 같은 API 의 응답 종류 (성공·빈 목록·오류·로딩) | 케이스 | 목업 규칙의 이름 뒷부분 |
| **중간 창구** | 브라우저와 프론트 사이에서 요청을 받아 목업/실제로 나누는 서버 | 프록시 | `proxy/` |
| **코멘트** | 요소나 범위에 남기는 의견. 깃랩 이슈에 저장됨 | 스펙코멘트 | 깃랩 이슈 |
| **이슈** | 한 화면의 코멘트가 모이는 깃랩 이슈 | 깃랩 이슈 | 스펙의 `issue` |
| **기획 건** | 갈래(브랜치)별로 따로 보는 기획 단위 | 갈래, 워크트리 단위 | `plans.yaml` |
| **스냅샷** | 어느 시점의 기획안과 코드 상태를 보관한 것 | 보관본, 버전 | `snapshots/` |

## 관계 한눈에

```
기획 건 ─ 가진다 ─▶ 화면 ─ 포함한다 ─▶ 요소
                      │                  │
                      │                  ├─ 근거를 둔다 ─▶ KB 항목 (설명의 원본)
                      │                  └─ 찾는다 ──────▶ 실제 화면의 버튼·입력창 (locator)
                      │
                      ├─ 코멘트가 모인다 ─▶ 이슈
                      └─ 호출한다 ─▶ API ─ 가진다 ─▶ 경우 (목업 응답)    ← 지금은 연결 정보 없음

스냅샷 = 특정 시점의 KB + 코드
```

## 아직 비어 있는 곳 (다음에 채울 후보)

- **화면 ↔ API**: 어느 화면이 어느 API 를 쓰는지 적은 곳이 없습니다.
- **요소의 `description` / `behavior` / `since`**: 스펙 예시에서 대부분 비어 있습니다.
- **용어 통일**: 화면/페이지, 요소/항목처럼 두 이름이 섞여 있습니다. 하나로 정할지 정해 주세요.

## 새 용어를 추가하는 법

1. 표에 한 줄을 추가합니다. (쓰는 이름, 한 줄 뜻, 같은 말, 어디에 있나)
2. 같은 뜻의 다른 이름이 이미 있으면 새로 만들지 말고 "같은 말" 칸에 적습니다.
